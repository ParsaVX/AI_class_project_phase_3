# پروژه سوم: سیستم پیشنهاددهنده هوشمند کتاب و فیلم

## فعالیت‌های انجام‌شده

- طراحی پرسش‌های تحلیلی برای هدایت بررسی داده‌ها
- محاسبه آمار توصیفی، از جمله میانگین و واریانس امتیازها و تعاملات کاربران
- مصورسازی داده‌ها و تولید نمودارهای تحلیلی با Matplotlib
